# Change Log

## [Unreleased]

- Jump to the end of the constructor on the component file

## [Added]

- v1.0.0 - Initial release, supports adding to the imports statement on modules and standalone components
- v1.1.0 - Fixes a bug, improves documentation
- v1.2.0 - Adds the auto mode, which looks for modules first and then standalone components, auto mode is now the default
- v1.3.0 - Adds go to constructor, navigates to the corresponding component and sets the cursor at the end of the constructor's parameters
- v1.4.0 - New way to look for modules or standalone components, moving upwards from the current file until a module or component is found, or a stop directory is reached
